# PEX 01 — Aprenda Fácil

## Resumo
O projeto **Aprenda Fácil** tem como objetivo facilitar o acesso a conteúdos educacionais
de forma simples, organizada e acessível, utilizando recursos tecnológicos para apoiar
o aprendizado de diferentes públicos.

## Objetivo
- Criar uma solução digital voltada à educação
- Organizar conteúdos de forma clara e intuitiva
- Aplicar conceitos aprendidos no curso de ADS

## Problema abordado
Muitos estudantes enfrentam dificuldades para encontrar conteúdos educacionais
organizados, acessíveis e de fácil compreensão em um único lugar.
